## 컨셉 F — Light and Neon (2026-11-13) — concept-f.html
- 유영님 방향 전환: 제미나이 이미지 뽑기가 어려워 "직접 찍은 사진 + 제 인터랙션"으로. 일본 나오시마 미술관에서 직접 찍은 네온 작품 사진(IMG_4411.HEIC, 사진 속 인물은 유영님 본인, 삭제 허락).
- 구성: 온보딩 = 제임스 터렐 작품 보는 느낌(파란 방, 분홍 빛 한 장, 스크롤/Enter로 빛 속으로 걸어 들어감) → 메인 = 네온 벽 사진. 벽의 글자 자리에 프로젝트 제목이 네온 글자로 켜지고(마우스 올리면 그 글자만 밝아짐), 클릭하면 카드로 열림.
- 사진 편집: 사람과 그림자를 지우고 바닥 질감을 채움(assets/photos/naoshima-wall.jpg). 바닥 왼쪽에 흐릿한 흔적이 약간 남을 수 있음.
- 주의: 사진 속 네온 작품은 다른 작가의 작품(브루스 나우먼 "One Hundred Live and Die"로 보임, 미술관 설명판 확인 필요). 원래 글자를 지우고 프로젝트 제목으로 덮었지만 공개 포트폴리오에 쓸 땐 출처/허가 확인 권장.
- 온보딩 빛은 제임스 터렐 레퍼런스(파란 방 + 분홍 사각 빛)를 코드로 재현.
- 단독 파일: docs/yuyoung-light-and-neon.html

## 컨셉 F 메인 v9 — UX 점검 (2026-11-13)
유영님 요청: UX/인터랙션 디자이너 포트폴리오이므로 사용성 문제를 먼저 점검.
고친 것:

- About · Contact 버튼을 항상 보이게(연락처가 원 안 카드에만 숨어 있던 문제).
- 움직이는 카드 클릭이 어렵던 문제: 카드에 마우스를 올리면 회전이 거의 멈춤.
- 빈 카드 "+"가 추가 버튼처럼 보이던 문제 → "Soon" 표시, 누를 수 없는 모양.
- 키보드: 반복 카드·빈 카드는 탭 순서에서 제외(프로젝트 5개만), 포커스 테두리 강화, 카드 열면 닫기 버튼으로 포커스 이동, 닫으면 원래 자리로 복귀, Esc로 닫기.
- 움직임 줄이기 설정(prefers-reduced-motion) 존중: 자동 회전·떠다니기·밀려나기 끔.
- 같은 방문 중 다시 열면 온보딩 건너뜀(직접 검증은 못 함).
남은 것(유영님 결정): 카드 16장 중 6장이 빈 칸·5장이 반복이라 "작업이 적다"는 인상 → 프로젝트 수에 맞춰 줄일지. 카드 이미지가 앱 캡처라 구분이 어려움 → 프로젝트 대표 이미지. 상세 카드 내용(역할·과정·결과) 보강. 한/영 표기 통일.
